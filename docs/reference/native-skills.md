# Native specialist workflows

Start with the [installed guide](../../templates/native-skills.md), which is bundled by `allstack init`. The primary interface is a directly invocable skill in Codex or Claude. Independent shaping, planning, source review, and application QA need no delivery run or task.

Original methods are versioned under [skills](../../skills). The installer packages identical method bodies for both hosts and adds a host-specific capability note. Native methods use the host's current tools and permissions. Existing managed plan/build calls retain their stricter tool scope; their restrictions do not apply to an independent native invocation.

## Durable services

AllSource continues to validate managed-run event chains and exact-commit receipts. Chronis owns delivery claims and completion. Prime retains source-linked context. Standalone `remember` records a bounded summary plus the digest of an existing Markdown document under docs, then reads the actual Prime node back. Repeated identical writes reuse the binding. Source changes create a distinct historical binding rather than silently replacing earlier evidence.

`recall` reads the repository's local Prime memory, combines standalone knowledge with retained delivery outcomes, and returns context only. An absent local memory returns an empty result without creating a store. Open the cited source and compare its recorded digest before treating a historical note as current. Hosted synchronization and vector search are outside this local preview.

## Native work to managed shipping

`adopt` accepts the completed native candidate, indexed request, existing accepted plan, and frozen policy. It requires commit authority, an authorized live feature branch, real initialized Chronis, and explicit staging of new files. It uses the existing snapshot, task setup, accepted-plan, handoff, verification, and publication paths without invoking a model again. Adoption does not imply that the candidate passed any checks.

`current` folds and validates AllSource histories to discover one active job. It refuses ambiguous or oversized discovery; explicit run commands remain available. Skills keep those protocol identifiers inside tool calls. Changing hosts preserves immutable scope and advances ownership; native tools outside managed calls remain under host policy rather than epoch fencing.

See the [application request](native-application-request.md) for the concrete expense-filter job used to verify native planning, real implementation, source review, actual CLI QA, source-linked recall, and exact-commit delivery.
