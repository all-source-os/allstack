## Limits and acceptance boundary

AllSource PR #370 includes the inherited Criterion compilation prerequisite. CI run 40678542842 exhausted its dependency-phase deadline before running benchmarks. A dependency-only recipe separates registry compilation from real Core library compilation. Local nightly graph comparison matched all 506 registry units, and the workflow enforces that identity again at runtime. The existing benchmark cases, optimization flags, thresholds and 285-second phase limits remain intact. The amended application commit passed all four native gates again, with 165 executed tests and five existing ignores; CI remains the execution check for the new Linux recipe.

Both authenticated hosts run on the same machine. This proves host handoff and durable ownership across Codex and Claude, not transport between physical machines. Five application tests require model assets, OCR or hosted credentials and remain ignored. No deployment, merge, new credential or hosted-sync operation is part of this qualification.

Merge mode and required-check enforcement are separate forge settings. Exact-commit local gates and observed CI results must be reported against their actual authority, without treating a rebase-only setting as a required-check rule.
